Finding your files

How to add your Jagged Alliance 2 files

You need a copy of the game you already own, installed on this computer. This page never downloads the game for you.

1. What we are looking for

One folder, called Data, from your Jagged Alliance 2 install. You do not pick files one by one — you pick that single folder and we read what we need from inside it. It contains the game's .slf archives, for example:

  • JAGGED ALLIANCE 2.SLF, SPEECH.SLF, MUSIC.SLF, MAPS.SLF, SOUNDS.SLF, ANIMS.SLF …
  • plus subfolders such as TILECACHE and NPCDATA.

The list on the previous screen is the full set for your edition. Anything shown there is read from your folder; nothing else is touched.

2. Where that folder is

GOG — in GOG Galaxy, open Jagged Alliance 2, click the gear beside Play and choose Manage installation › Show folder. Otherwise:

  • Windows
    C:\GOG Games\Jagged Alliance 2 Gold\Data
  • Linux / macOS
    ~/GOG Games/Jagged Alliance 2 Gold/game/Data

Steam — right-click Jagged Alliance 2 in your Library and choose Manage › Browse local files. A window opens on the game folder; Data is inside it. Usually:

  • Windows
    C:\Program Files (x86)\Steam\steamapps\common\Jagged Alliance 2\Data

Disc or other install — wherever you installed it, the Data subfolder inside the game folder.

Not sure you have the right one? The correct folder has files ending in .slf directly inside it. If you can see ja2.exe but no .slf files, you are one level too high — open Data inside it. You can also just pick the game folder itself and we will find Data for you.

3. Uploading it

  • Tick the three confirmation boxes (they unlock the button).
  • Click Choose your Data folder.
  • Your browser opens a folder picker. Select the Data folder and confirm when it asks for permission to view it.
  • Each file is checked and uploaded, ticking off the list as it goes. A full install is around 1–1.5 GB, so it takes a few minutes on a normal connection.
  • When it finishes the game starts by itself. You only do this once — after that, signing in on any computer is enough.

If it does not work

  • "Windows blocks this folder" — browsers refuse to open anything inside Program Files, which is where Steam installs by default. Copy the Data folder to Documents or Desktop and pick the copy. GOG installs under C:\GOG Games\ are fine as they are.
  • "Does not look like a complete install" — the folder is missing files, or is a modified/modded copy. Only unmodified retail files are accepted, because every file is checked by name, size and checksum.
  • No folder picker appears — use Chrome, Edge or Brave on a desktop computer. Firefox and Safari cannot open folders this way.

Nothing leaves your machine except the game files listed on the previous screen, and they go only to your own account's private locker.
